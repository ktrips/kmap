```html
本業を続けながら、"週末"という限られた時間だけでiOSアプリを企画・開発し、収益化まで進める――。
本書は、Google Maps SDKを使った位置情報×ゲーミフィケーションアプリ「Komap」の開発を題材に、金曜の夜から月曜の朝までの48〜60時間で、企画設計からコア機能のMVP実装、Web版の本番公開、App Store審査提出までを完走させる実践的方法論を解説する一冊です。

<b>本書はこんな方におすすめです</b>
<ul>
<li>プログラミング経験はあるが、位置情報アプリやGoogle Maps SDKは初めて</li>
<li>本業が忙しく、まとまった開発時間が取れないエンジニア・個人開発者</li>
<li>「作って終わり」ではなく、リリースして収益化まで到達したい方</li>
<li>ノーコードではなく、Swift/SwiftUIによるネイティブ開発を学びたい方</li>
</ul>

<b>本書の特徴</b>
<ul>
<li><b>「1つの週末」フレームワーク</b>：垂直スライス思考・タイムボックス法・スコープ削減ルールなど、時間制約下で「作りきる」ための意思決定手法を具体的に提示</li>
<li><b>実体験ベースの技術解説</b>：Xcodeプロジェクト構築、古地図オーバーレイ表示、GPS軌跡描画、チェックポイント／御朱印のゲーミフィケーション、AIコンテンツ生成、Firebaseによるデータ永続化・クラウド同期、Apple Watch対応、Vite+ReactによるWeb版展開まで、実際に動いたコードと実際にハマった落とし穴を紹介</li>
<li><b>収益化・マーケティング編を独立して収録</b>：収益化モデルの選び方、ASO（アプリストア最適化）、低予算マーケティング、グロースサイクル、費用構造とROI分析、法務・プライバシー・倫理まで、非エンジニアにも読めるよう平易に解説</li>
<li><b>起業家の思考法を収益化戦略に応用</b>：スティーブ・ジョブス、ピーター・ティール、イーロン・マスクという3人の起業家哲学を、個人開発者の意思決定にどう活かすかを独自の視点で展開</li>
</ul>

全21章＋付録（用語集・開発チェックリスト・参考リソース）構成。第I部（開発編）はSwift/SwiftUI・Google Maps SDK・Firebase・Apple Watch・Web版展開までを扱う実践パート、第II部（収益化・マーケティング編）は企画力とビジネス視点を養うパートです。

「アイデアはあるが時間がない」を言い訳にしたくないすべての個人開発者へ。次の週末、あなたのアプリをリリースしましょう。
```
